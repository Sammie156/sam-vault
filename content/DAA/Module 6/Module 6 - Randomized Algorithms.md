This module rests on the expected behavior of algorithms and how we can use randomness to prevent the worst case behavior. 

### **TOPICS**:
- [[Quick Sort]]
- [[Random Hiring Problem]]
- [[Finding Minimum Global Cut]]

### **IDEA**:
The idea of this module is to show how randomized behavior can prevent from getting the worst case scenario. With random input and random distribution, and using probabilistic expectations, we make sure that the algorithm runs on the best case scenario.

- In Quick Sort, we see that the best case scenario is when we pick a random pivot.
- In Hiring Problem, we see that the best case scenario occurs when the input is all randomly distributed.
- And in Karger's Theorem, we see that we can easily get the minimum cut of the graph by picking random edges, minimizing the chance to pick edges that belong to the minimum cut.
